# Brammer 2008

[источник] Gabriel B. Brammer, Pieter G. van Dokkum, P. Coppi, «EAZY: A Fast, Public Photometric Redshift Code», The Astrophysical Journal, т. 686, вып. 2, с. 1503–1513, 2008.
[источник] Аннотация: We describe a new program for determining photometric redshifts, dubbed EAZY. The program is optimized for cases where spectroscopic redshifts are not available, or are only available for a biased subset of the galaxies.
[порождено] Зачем проекту: шаблонный код photo-z EAZY — альтернатива kNN, не зависящая от обучающей выборки.
