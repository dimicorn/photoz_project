# L2 — тезисы

1. После удаления вероятных звёзд с zLePHARE < 0.01 и ограничений i < 24.5, H < 24.8 в COSMOS2020 осталось 121 791 источников. После дополнительного удаления объектов без измерений в нужных полосах, без LePHARE photo-z или sSFR, а также 22 вероятных звёзд с zspec = 0.0 итоговая выборка составила 112 387 источников. (с. 4)

2. Спектроскопическая выборка CSRC (14 477 объектов с CL > 95) демонстрирует недостаток объектов с z > 1.5 и более тусклых объектов (i ≳ 23). (с. 4–5)

3. UMAP-вложение семимерного пространства цветов u−g, g−r, r−i, i−z, z−y, y−J, J−H (n_neighbors=70, min_dist=0.00, манхэттенская метрика во входном пространстве) выявило тонкое, почти двумерное многообразие в трёхмерном пространстве вложения с непрерывными, монотонными и локально примерно ортогональными трендами красного смещения и sSFR. (с. 4, 7–8)

4. Порог для доли аномалий foutlier установлен на |∆z/(1+z)| > 0.15; точность оценивается также по σNMAD и bias — среднему dz = (z_phot − z)/(1 + z). В проекте bias определяется как медиана dz, поэтому значения напрямую не сравниваются. (с. 9)

5. При обучении на spec-z в диапазоне 1.8 < z < 2.0 доля выбросов foutlier у nearest-z примерно на порядок выше, чем у UMAP-kNN-z. (с. 11)

6. При обучении на spec-z в области z > 1.5 UMAP-kNN-z даёт на 23% меньший foutlier (0.0392 против 0.0509), на 2,3% меньший σNMAD (0.0334 против 0.0342) и на 15% меньший модуль bias (−0.0309 против −0.0362) по сравнению с colors-kNN-z. (с. 14)

7. Для UMAP-kNN-z выбраны трёхмерные вложения без densMAP, без перемасштабирования входных цветов, с манхэттенской метрикой во входном пространстве, min_dist=0.00 и n_neighbors=70; предсказание — медиана красных смещений k=15 ближайших соседей во вложении. (с. 17)

8. Для colors-kNN-z выбрана медиана красных смещений k=11 ближайших соседей в пространстве цветов с манхэттенской метрикой: медиана лучше среднего по foutlier и σNMAD и несколько лучше по bias. (с. 15)

9. Неопределённости из-за выбора гиперпараметров оцениваются по вариациям ±15% с использованием варианта пятикратной перекрёстной проверки. Для неопределённости из-за конечного размера тестовой выборки используются 25 bootstrap-реализаций; для SOM и UMAP отдельно учитывается разброс по 25 вложениям с random seed 0–24. Эти вклады рассчитываются отдельно и суммируются в квадратуре. (с. 7, 17–18)

10. UMAP-kNN-z сопоставим с colors-kNN-z по полным неопределённостям по всей области z, несмотря на дополнительные источники вариативности (вложения, гиперпараметры); неопределённости SOM-методов значительно выше, особенно при z < 0.5 и z > 1.5. (с. 23–24)
