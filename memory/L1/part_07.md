## Uncertainties in Statistics (с. 18–21)

Главное утверждение: неопределённости метрик производительности (foutlier, NMAD, Bias) для четырёх алгоритмов предсказания красного смещения количественно оцениваются через вариацию гиперпараметров, bootstrap resampling и случайные сиды, после чего вклады складываются в квадратуре.

Метод: для каждого гиперпараметра значения варьируются на ±15% (например, k=11 → 9 и 13 для colors-kNN-z; n neighbors=70 → 69 и 80 для UMAP-kNN-z; grid size=75×150 → 69×138 и 80×160 для SOM-z; sigma=1.0 → 0.85 и 1.15; learning rate=0.8 → 0.68 и 0.92), используется five-fold cross-validation, 25 bootstrap-реализаций и 25 наборов вложений SOM и UMAP с random seed 0–24.

Результат: для colors-kNN-z (с. 18–19) — наименьшие неопределённости, так как нет шага снижения размерности; для SOM-z (с. 19–20) — неопределённости больше, чем для nearest-z, поскольку объекты в ячейках без обучающих данных игнорируются; для UMAP-kNN-z (с. 20–21) — учтены вклады n neighbors и k.
