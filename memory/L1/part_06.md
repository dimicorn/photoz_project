## Оптимизация SOM-вложений и UMAP-kNN-z (с. 16–17)

Для предсказания красных смещей оптимизированы Self-Organizing Map (SOM) и UMAP-вложения. Лучший SOM — сетка 75×150 ячеек, метрика Манхэттена, σ=1.0, скорость обучения 0.8 (с. 16). Входные цвета без перемасштабирования в цветовом пространстве ugrizyJH превосходят стандартизированные: разные динамические диапазоны несут полезную информацию (с. 17). Для UMAP-kNN-z выбраны трёхмерные вложения без densMAP, метрика Манхэттена, min dist=0.00, n neighbors=70; предсказание — медиана красных смещений k=15 ближайших соседей (с. 17). Медиана заметно лучше среднего по foutlier и σNMAD и несколько лучше по bias (с. 17). Неопределённость оценивается бутстрапом и разбросом по 25 запускам с разными случайными семенами (с. 17). Пять фолд-кросс-валидация использовалась для количественной оптимизации гиперпараметров (с. 17).
