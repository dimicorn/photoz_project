# Данные

## `raw/happy_[ABCD].txt`

Каталоги *Happy* (Beck et al. 2017, arXiv:1701.08748) из репозитория
COINtoolbox/photoz_catalogues (лицензия GPL-3.0 — `raw/LICENSE_photoz_catalogues`;
описание авторов — `raw/README_happy.md`). Галактики SDSS DR12 со спектроскопическим z.
Скачаны 2026-09-30 с `raw.githubusercontent.com/COINtoolbox/photoz_catalogues/master/Happy/`.

| Файл | Строк | Роль |
|---|---|---|
| `happy_A.txt` | 74 950 | обучающая: как спектроскопическая выборка SDSS DR12 |
| `happy_B.txt` | 74 900 | проверочная, то же распределение, что у A |
| `happy_C.txt` | 60 315 | проверочная: больше объектов с большими ошибками фотометрии |
| `happy_D.txt` | 74 642 | проверочная: как фотометрическая выборка SDSS DR12 (смещена относительно A) |

Формат: разделитель — пробелы, первая строка — заголовок, начинается с `#`.

| Столбец | Что это | Единицы |
|---|---|---|
| `id` | SDSS ObjID | — |
| `mag_r` | величина r (dered modelMag) | AB, mag |
| `u-g`, `g-r`, `r-i`, `i-z` | цвета | mag |
| `z_spec` | спектроскопическое красное смещение | — |
| `feat1..feat5` | `mag_r` и четыре цвета, стандартизованные по среднему и σ **Happy A** | — |

## Известные особенности

- `feat*` нормированы по A: для C и D средние не нулевые — так и задумано.
- В C и D распределение величин и цветов сдвинуто к тусклым и красным объектам:
  обучение на A для них нерепрезентативно — это предмет проекта, не дефект.
