# INDEX.md — где что лежит

- `AGENTS.md` — правила работы агента в проекте.
- `STATUS.md` — где работа сейчас; читать в начале сессии.
- `diary.md` — журнал проекта; только дописывается.
- `data/README.md` — описание каталогов Happy: столбцы, роли выборок.
- `data/raw/happy_A.txt` — обучающая выборка; только чтение.
- `data/raw/happy_B.txt`, `data/raw/happy_C.txt`, `data/raw/happy_D.txt` — проверочные выборки; только чтение.
- `paper/paper.pdf` — Ashmead et al., arXiv:2512.09032v2.
- `memory/L1.md` — реферат статьи по частям (сжатие учебным агентом скриптом курса cascade.sh); `memory/L1/` — сжатия отдельных частей; `memory/L2.md` — тезисы со страницами и сверкой; `memory/L3.md` — одна строка.
- `src/photoz.py` — kNN photo-z: `load()`, `predict_knn()`, `metrics()`; пишет `results/`.
- `checks/check.py` — проверка результата (критерий готовности); только чтение.
- `results/metrics.csv` — метрики по выборкам B, C и D.
- `results/predictions_B.csv`, `results/predictions_C.csv`, `results/predictions_D.csv` — photo-z по галактикам.
- `ontology.yaml` — онтология: классы, отношения, правила; только чтение.
- `ontology/` — заметки классов (создаёт `src/graph.py classes`).
- `notes/` — заметки объектов работы; `tasks/` — задачи со статусами; `reports/` — отчёты.
- `src/graph.py` — запись заметок из YAML (`apply`) и смена статуса задачи (`status`).
- `checks/check_graph.py` — проверка графа по онтологии; только чтение.
- `library/openalex_photoz_library.jsonl` — личная библиотека: 20 работ OpenAlex с аннотациями.
- `library/queries/` — ответы инструментов research_mcp и Crossref с provenance (01–16).
- `reports/my_search_report.md` — BM25 и векторный поиск по библиотеке, 5 запросов.
- `reports/Качество photo-z при смещении выборки.md` — отчёт по метрикам B, C, D.
- `REPORT_HW1.md` — отчёт по ДЗ 1.
- `src/ask.py` — ответы на компетентностные вопросы по графу.
